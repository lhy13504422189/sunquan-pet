# 孙权像素桌宠

王者荣耀·孙权 Q版像素画桌宠，适配 DSH-GO。

## 当前状态

v4 版本已上传，包含基础待机帧和点击冒爱心动画。

说实话现在还很简陋：
- 只有一张静态待机图，没有呼吸、眨眼这些细节
- 爱心动画也比较简单，就6帧从头顶右上方冒出然后飞走
- 其他状态（思考、工作、睡觉、行走等）都还没做，暂时全部映射到待机帧
- 点击交互只有冒爱心，左右侧点击没有区分反应

这些都是接下来要补的。

## 使用方式

### DSH-GO（Android）
1. 手机下载 `sunquan-v4.zip`
2. DSH-GO 中：设置 → 宠物 → 导入

### Windows 桌面版
还在开发中，预计用 C# WPF 实现透明窗口 + 逐像素 alpha 渲染。完成后会在这里更新。

## 后续计划

按优先级逐步补充：
1. 待机动画（呼吸起伏 + 正确位置眨眼）
2. 完整状态机（thinking / working / error / happy / notification / sleeping / waking / roam）
3. 点击交互细化（左侧头 / 右侧头不同反应）

## 素材来源

角色形象参考王者荣耀孙权原皮肤，像素画网格由人工逐格填写颜色代码还原，共 35×47 网格、32 种颜色。
